Alfred - Privacy Policy

Last updated: September 25, 2026

Alfred is a private, self-hosted personal assistant used only by its owner. It has no other users and is not available to the public.

What Google data Alfred accesses

  • Gmail (read-only): reads the owner's email messages to summarize the inbox and answer questions about specific emails. Alfred cannot send, delete, or modify email.
  • Google Calendar: reads the owner's calendar events, and creates events only when the owner approves each one.

How the data is used and stored

  • Data is used only to answer the owner's own requests.
  • All processing happens on computers the owner owns and operates at home, using a locally run AI model. Google data is not sent to any third-party service.
  • Alfred does not keep copies of email or calendar data beyond what is needed to answer a request, apart from ordinary conversation history on the owner's own machines.
  • Data is never sold, shared, or used for advertising.

Google API Services User Data Policy

Alfred's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
